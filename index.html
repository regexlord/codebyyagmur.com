Robotics Prototype

Educational Quadruped Robot

{/* Extended technical description */}

Dogduino is a cost-effective educational quadruped robotics platform engineered around an ESP32 microcontroller and a PCA9685 16-channel 12-bit PWM servo driver. The chassis coordinates 8 servo-driven legs to achieve smooth omnidirectional locomotion.

The project implements mathematical inverse kinematics (IK) algorithms to translate three-dimensional gait coordinates into synchronized joint angles. It features dynamic center-of-mass balancing, customized trotting rhythms, and parameterizable leg clearance.

Integrated with real-time Bluetooth wireless communication, the system receives low-latency commands from a companion mobile controller interface, executing smooth transitions between walking, crouching, sitting, and active standing modes.
